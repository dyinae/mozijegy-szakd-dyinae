A mozi jegyfoglaló alkalmazás elindítása
########################################
Követelmények:
Node.js V18+
Angular CL: npm install -g @angular/cli
########################################
A frontend és backend nek kell 1-1 saját terminál
Backend elindítása:
cd backend
npm install
npm run dev
########################################
A frontend és backend nek kell 1-1 saját terminál
Frontend elindítása:
cd frontend
npm install
ng serve
########################################
URL-ek:
Frontend: http://localhost:4200
Backend API: http://localhost:3000
Swagger UI: http://localhost:3000/api-docs
